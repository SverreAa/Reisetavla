# Ikoner

Strekikonene fra appen som frittstående SVG-filer, tegnet i `#0e1a2b` (`ink` i lyst tema). Et `<img>` kan ikke arve farge, så i appen bør du bruke komponenten `Icon`, som tegner i `currentColor`. Transportmidlene er `bus`, `coach`, `rail`, `metro`, `tram`, `water`, `air` og `foot`. Grensesnittikonene er `pin`, `me`, `warn`, `star`, `share`, `swap`, `close` og `board`.
