# Toast

Kort bekreftelse etter en handling, nederst midt på skjermen i 1,8 s.

- Beskriv resultatet i perfektum eller som tilstand: «Lagret i Mine reiser», «Lenken er kopiert».
- `ink`-bakgrunn med `bg`-tekst, så den er tydelig i begge temaer.
- Ingen knapper i toasten. Det som må angres, får en egen kontroll.
