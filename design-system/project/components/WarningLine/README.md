# WarningLine

Avviksmelding inne i et kort.

- `warn` (standard): forsinkelser og avvik fra Entur, med teksten slik operatøren skrev den, på norsk når det finnes.
- `crit`: innstillinger, med teksten «Del av reisen er innstilt.».
- Trekantikonet står alltid med, og bakgrunnen er 10 % av tonen over `surface`.
