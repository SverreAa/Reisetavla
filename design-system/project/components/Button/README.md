# Button

Tekstknapp for handlinger i bunnark og tom-tilstander.

- `primary` (standard): `accent` med `accent-ink`. Høyst én per skjerm eller ark, for den handlingen arket finnes for («Del …»).
- `ghost`: `surface-2` med `ink`, for alt annet («Kopier lenke», «Lukk», «Prøv igjen»).
- Minst `touch-target` høy, radius `radius-14`. Verb først, vanlig setningsstavelse, ingen utropstegn.
- I søk og resultater brukes IconButton; tekstknapper hører hjemme i ark og feiltilstander.
