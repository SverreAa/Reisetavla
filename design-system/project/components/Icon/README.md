# Icon

Strekikonene: 20 × 20-rutenett med 1,6 strek og avrundede ender, tegnet i `currentColor`.

- Standardstørrelse `icon` (18 px). I linjebrikker og gangbrikker `icon-sm` (16 px) med 2 i strek.
- Ikonet arver tekstfargen. Gi det aldri en egen farge utenom modusfargen i ModeChip.
- De samme ikonene finnes som filer under Ikoner.
