# LinePill

Linjebrikken: ikon og linjenummer på linjens farge. Det er den viktigste gjenkjenningen i appen.

- Bruk Enturs `presentation.colour` og `textColour` når de finnes (`colour`, `textColour`). Ellers modusfargen og `on-mode`.
- Linjenummeret er satt i `pill` (Overpass 800, tabulære tall), med radius `radius-8`.
- Uten linjenummer vises modusnavnet («Tog»).
- T-bane (`m-metro`) med hvit tekst er under 4.5:1 i lyst tema. Se tokennotatet.
