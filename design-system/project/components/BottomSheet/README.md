# BottomSheet

Ark som glir opp nederfra for oppgaver ved siden av hovedflyten, som deling.

- `scrim` bak; trykk utenfor lukker. Arket har grep-håndtak, `radius-24` øverst og bunnmarg med safe-area-innrykk.
- Animasjon: 0,22 s inn nedenfra. Ingen animasjon ved redusert bevegelse.
- Tittel i `sheet-title`. Knappene ligger nederst: én `primary` og resten `ghost`.
- Oppdatering av listen i bakgrunnen er satt på pause mens arket er åpent.
