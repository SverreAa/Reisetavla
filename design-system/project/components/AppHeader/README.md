# AppHeader

Toppen av hver skjerm: ordmerket «Reisetavla» til venstre og datakilden som StatusBadge til høyre.

- Ordmerket er satt i tekst, ikke tegnet: «Reise» i `ink`, «tavla» i `accent`, stilen `wordmark`. Det finnes ingen logofil.
- Ligger øverst i `rt-screen`, under safe-area-innrykket. Ruller med innholdet; ingen fast toppstolpe.
- Gi `live` fra tilkoblingssjekken mot Entur. Skjul statusen (`status={false}`) bare på skjermer uten data, som innstillinger.
