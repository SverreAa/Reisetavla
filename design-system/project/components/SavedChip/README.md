# SavedChip

En lagret reise som snarvei, i en horisontal rad under AppHeader.

- Navnet er «Fra → Til» eller «Fra → avganger». Brukeren kan ikke gi egne navn.
- Trykk på navnet åpner reisen; krysset fjerner den uten bekreftelse, og en Toast sier «Fjernet fra Mine reiser».
- Raden ruller sidelengs og blør ut i sidemargen. Skjul raden når listen er tom.
