# TabBar

Hovedmeny nederst på skjermen med Reiser, Avganger og Mine reiser.

- Tillegg i designspråket; appen har den ikke ennå. Den skiller de tre oppgavene som i dag deler én skjerm.
- `surface` med `line` øverst, og bunnmarg med safe-area-innrykk. Aktiv fane er `accent` med `aria-current="page"`.
- Hver fane har ikon og ord, og er minst `touch-target` høy. Høyst fire faner.
