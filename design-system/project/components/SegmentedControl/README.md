# SegmentedControl

Valg mellom to til fire likeverdige moduser, som «Nå / Avreise / Ankomst».

- Spor i `surface-2`, valgt knapp i `surface` med `shadow` og `ink`; de andre `muted`.
- Bytte gjelder med en gang, uten lagre-knapp. Avreise og Ankomst viser dato- og tidsfelt under.
- Bruk ikke kontrollen til filtre som kan kombineres; da gjelder ModeChip.
