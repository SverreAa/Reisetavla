# Switch

Av/på-bryter for innstillinger som gjelder til de endres: ekskluderte ruter, avstigningsvarsel, «Legg ved dette reisesøket».

- 50 × 30 px, `radius-full`, `role="switch"` og `aria-checked`. På er `accent`, av er `muted`; knotten er 24 px `surface` og glir på 0,15 s.
- `label` er påkrevd og blir `aria-label` («Ekskluder Trikk 19»). Sett alltid en synlig tekst ved siden av bryteren også, og gjerne et statusord («Med» / «Ekskludert»).
- Raden rundt er minst 44 px høy. Bruk ikke bryter for engangshandlinger; da gjelder Button.
