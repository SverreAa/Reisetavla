# IconButton

Rund ikonknapp på `touch-target` (44 px) for handlinger på skjermen: lagre, del, bytt.

- Standard: `surface` med `shadow`, for knapper som ligger rett på `bg` (lagre, del).
- `inset`: `surface-2` uten skygge, for knapper inne i et kort (byttknappen i SearchCard).
- `pressed` farger ikonet `accent` og fyller det, som stjernen for en lagret reise.
- `label` er påkrevd og beskriver handlingen («Lagre reisen», «Bytt fra og til»).
- Appen bruker i dag 42 px og 40 px. Designspråket hever dette til 44 px.
