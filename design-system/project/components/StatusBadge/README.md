# StatusBadge

Viser om tallene på skjermen er sanntid fra Entur eller eksempeldata.

- `live`: grønn prikk (`ok`) som pulserer i 2 s, tekst «Live · Entur».
- Ikke live: oransje prikk (`warn`), tekst «Eksempeldata». Mens appen sjekker: «Kobler til».
- Teksten står i versaler med stilen `status`. Fargen er aldri alene; ordet bærer betydningen.
