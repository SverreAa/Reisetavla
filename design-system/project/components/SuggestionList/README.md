# SuggestionList

Forslag under et felt mens brukeren skriver. «Min posisjon» står alltid øverst.

- Hver rad har en ikonflis (`radius-10`, `surface-2`): siktekorn i `accent` for posisjon, buss for stopp og nål for adresse.
- Navn i `body-strong`, sted under i `caption` og `muted`. Raden er minst `touch-target` høy.
- Ligger over innholdet under feltet. Lukkes med Escape, og Enter velger første treff etter posisjon.
