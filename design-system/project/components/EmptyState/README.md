# EmptyState

Står i stedet for resultatlisten når det ikke er noe å vise, eller når noe gikk galt.

- Tittel sier hva som skjedde («Ingen reiser funnet»), og teksten sier hva brukeren kan gjøre.
- Feil får ghost-knappen «Prøv igjen». Tomme svar har ingen knapp.
- Ingen unnskyldninger og ingen illustrasjoner.
