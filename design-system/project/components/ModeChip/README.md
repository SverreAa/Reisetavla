# ModeChip

Av/på-brikke for ett transportmiddel. Flere kan være på samtidig.

- På: ramme og ikon i modusfargen (`m-bus`, `m-rail` …), bakgrunn 13 % modusfarge over `surface`, tekst `ink`.
- Av: `line`-ramme, ikon og tekst i `muted`. Ikon og ord skiller tilstandene, ikke bare fargen.
- Rekkefølge: Buss, Tog, T-bane, Trikk, Båt, Ekspressbuss, Fly. Raden ruller sidelengs.
- Endringer kjører søket på nytt etter 350 ms.
